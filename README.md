An explicitly invoked Codex skill for bounded development batches. A deterministic
Python runner collects native task results, journals external effects and executes
successors. Technical workers handle analysis, code, tests and review in separate
contexts; the user retains scope and final-merge decisions.

needed. Each run pins its scripts and instructions; installed updates do not
